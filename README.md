# Simple Python Scripts

This repo contains simple python automation scripts
- `downloads_cleanup.py` helps clean up your downloads directory. 
- `jungle_language.py` is a language translator that helps you translate English to Jungle Language
- `patch-gitlab_ci.sh` is a shell script that let's you update a gitlab.yml file
- `search-yml.sh` is a shell script that searches for a particular occurence of a string
